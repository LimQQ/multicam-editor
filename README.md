# 밴드 멀티캠 편집기

두 각도에서 찍은 공연 영상을 하나로 합칩니다.

- **소리로 자동 싱크** — 두 영상에 녹음된 연주 소리를 비교해서 시간차를 자동으로 찾아냅니다
- **원하는 곳에서 카메라 전환** — 전환 위치는 직접 지정
- **앞뒤 잘라내기** — 세팅하는 부분, 끝나고 정리하는 부분 잘라내기
- **페이드 인/아웃** — 시작과 끝은 검정에서 서서히(소리도 같이), 카메라 전환은 디졸브 또는 검정 페이드
- **싱글캠 모드** — 카메라가 한 대뿐이면 맨 위 **편집 모드** 에서 **싱글캠** 을 고르세요. 곡이 아닌 앞뒤 부분을 잘라내고, 첫머리에 곡 제목과 작곡가를 띄울 수 있습니다 (아래 ⑦ 참고)

---

## 1. 설치 (처음 한 번만)

`setup.bat` 을 더블클릭하세요. Python, ffmpeg, 필요한 라이브러리를 자동으로 깝니다.

> 이미 이 PC에는 설치가 끝나 있습니다. 다른 컴퓨터에서 쓸 때만 필요합니다.

## 2. 실행

`run.bat` 을 더블클릭.

---

## 3. 사용법

### ① 영상 두 개 열기

맨 위 **영상 열기...** 버튼으로 카메라 A, B 영상을 각각 엽니다.

- **카메라 A 가 기준**입니다. 타임라인의 시간, 전환점 시간은 전부 A 영상 기준.
- 해상도나 프레임이 서로 달라도 됩니다 (출력할 때 맞춰집니다).
- 세로 영상, 4K, 폰 촬영본 모두 열립니다.

### ② 소리로 자동 싱크 맞추기

**🔊 소리로 자동 싱크 맞추기** 를 누릅니다. 1시간짜리 영상도 보통 10~30초면 끝납니다.

끝나면 오른쪽에 이렇게 뜹니다:

```
B 영상이 A 보다 00:12.480 먼저 시작  (신뢰도 3.41 · 확실함)
```

**신뢰도**는 "정답 위치가 다른 후보들보다 얼마나 뚜렷한가"입니다.

| 신뢰도 | 뜻 |
|---|---|
| 2.5 이상 | 확실함 — 그냥 쓰면 됩니다 |
| 1.6 ~ 2.5 | 양호 |
| 1.25 ~ 1.6 | 보통 — 미리보기로 한 번 확인해 보세요 |
| 1.25 미만 | 불확실 — 아래 방법으로 직접 맞추세요 |

**싱크가 안 맞을 때 직접 맞추는 법**

1. 두 영상 모두에 잘 보이는 순간을 찾습니다 (스네어 첫 타, 심벌 치는 순간, 박수 등)
2. 그 순간으로 재생 위치를 옮깁니다
3. **시간차 B−A** 옆의 `−1f` `+1f` 버튼으로 B 미리보기가 A 와 같은 동작이 되게 맞춥니다
4. 숫자를 직접 입력하고 Enter 를 쳐도 됩니다

### ③ 자르기

- 남길 부분의 시작으로 이동 → **[ 시작점 지정 (I)**
- 남길 부분의 끝으로 이동 → **끝점 지정 ] (O)**
- **전체** 를 누르면 두 영상이 겹치는 구간 전부로 되돌아갑니다

타임라인에서 잘려나가는 부분은 어둡게 표시됩니다.

### ④ 카메라 전환점 지정

**방법 1 — 들으면서 실시간으로 (권장)**

**▶ 재생** 을 누르면 두 카메라가 동시에 재생되고 소리도 같이 납니다.
연주를 들으면서 바꾸고 싶은 순간에 `1`(A) / `2`(B) 키를 누르면 그 자리에 전환점이 찍힙니다.
실제 멀티캠 편집하는 방식 그대로입니다.

**방법 2 — 한 지점씩 정확하게**

1. 타임라인을 클릭하거나 이동 버튼으로 전환하고 싶은 지점으로 갑니다
2. **여기서 A 로 (1)** 또는 **여기서 B 로 (2)** 를 누릅니다
   - 미리보기 화면을 그냥 클릭해도 그 카메라로 전환점이 추가됩니다
3. 타임라인 색 띠에서 어느 구간에 어떤 카메라가 나오는지 바로 보입니다

**시작 카메라** 는 맨 처음에 나올 카메라입니다.

전환점은 오른쪽 **전환점 목록** 에서 확인/삭제할 수 있습니다. 목록을 더블클릭하면 그 위치로 이동합니다.

> 타임라인 배경의 물결무늬는 A 영상의 소리 크기입니다. 곡이 바뀌는 지점이나 쉬는 구간을 눈으로 찾을 때 쓰세요.

### ⑤ 페이드 / 전환 효과

**편집** 칸 맨 아랫줄에서 정합니다.

**페이드 — 시작 / 끝**

검정에서 서서히 밝아지며 시작하고, 서서히 어두워지며 끝납니다. **소리도 같이** 커지고 잦아듭니다.
`0` 을 넣으면 그 페이드는 없습니다. 기본값은 시작 1.0초 / 끝 1.5초입니다.

**전환 — 카메라가 바뀔 때**

| 선택 | 결과 |
|---|---|
| **디졸브 (겹치며 전환)** | 두 화면이 겹치면서 부드럽게 넘어갑니다. 멀티캠 편집의 기본입니다 |
| **검정 페이드** | 어두워졌다가 다음 카메라로 밝아집니다. 곡과 곡 사이처럼 확실히 끊고 싶을 때 |
| **없음 (바로 전환)** | 딱 잘라 바뀝니다. 박자에 맞춰 끊을 때 |

옆의 숫자가 전환에 쓰는 시간(초)입니다. 전환은 전환점을 **한가운데 두고** 앞뒤로 절반씩 나눠 씁니다.
0.5초 디졸브라면 전환점 0.25초 전에 시작해 0.25초 후에 끝납니다.

> **짧은 장면은 자동으로 줄어듭니다.** 예를 들어 1초짜리 장면에 0.8초 전환을 걸면 장면이 통째로
> 전환에 먹혀버리므로, 그 자리만 짧게(장면 길이의 절반 이하로) 줄입니다.
> 요약 줄에 `※짧은 장면은 자동 단축` 이라고 표시됩니다.

전환 구간과 페이드 구간은 타임라인 색 띠 위에 표시됩니다.

> 전환 효과를 넣어도 **전체 길이와 소리 위치는 그대로**입니다. 전환은 장면 사이에 시간을 끼워 넣는 게
> 아니라 양쪽 장면에서 절반씩 빌려 쓰기 때문입니다. 그래서 소리와 화면이 어긋나지 않습니다.

### ⑥ 영상 만들기

| 설정 | 설명 |
|---|---|
| 해상도 | 두 영상 중 화질 좋은 쪽에 맞추는 걸 권장 |
| 프레임 | `A 영상과 동일` 이 무난합니다 |
| **소리** | **소리가 더 좋은 쪽을 고르세요.** 전환과 무관하게 처음부터 끝까지 이 카메라 소리만 씁니다 |
| 화질 | 표준이면 충분합니다 |
| GPU 가속 | NVIDIA 그래픽카드가 있으면 훨씬 빠릅니다 (화질은 조금 손해) |

**💾 영상 만들기** 를 누르고 저장 위치를 정하면 끝입니다.

### ⑦ 싱글캠 모드

카메라가 한 대일 때 씁니다. 맨 위 **편집 모드** 에서 **싱글캠** 을 누르면 화면이 바뀝니다.
멀티캠에서 하던 작업(싱크, 전환점)은 숨겨질 뿐 지워지지 않으므로, 다시 **멀티캠** 을 누르면 그대로 돌아옵니다.

카메라 한 대로는 의미가 없는 자동 싱크, 전환점, 전환 효과, 두 화면 맞추기, 소리 선택만 빠지고
나머지(재생, 자르기, 페이드, 화면 보정, 내보내기 설정, GPU 가속, 프로젝트 저장)는 멀티캠과 똑같이 쓸 수 있습니다.

**곡이 아닌 앞뒤 부분 자르기**

영상을 열면 소리를 분석해 타임라인에 파형을 그려 줍니다. 조용한 부분과 연주하는 부분이 눈으로 구분됩니다.

1. 파형을 보고 곡이 시작할 만한 곳을 클릭한 뒤 재생해서 들어 봅니다
2. 곡이 시작하는 순간에 `I`, 끝나는 순간에 `O` 를 누릅니다 (재생 중에 눌러도 됩니다)
3. 맞추는 방법은 편한 것을 쓰면 됩니다
   - 타임라인의 **초록 선을 마우스로 끌기**
   - **곡 시작 / 곡 끝** 칸에 시간을 입력하고 `Enter` (예: `1:23.5`)
   - `←` `→` 로 1프레임씩 옮긴 뒤 다시 `I` / `O`

잘려나가는 부분도 들어 볼 수 있습니다. 시작점 앞에서 재생하면 거기서부터 곡 끝까지, 끝점 뒤에서 재생하면 영상 끝까지 나옵니다.
`Home` / `End` 로 곡 시작과 곡 끝으로 바로 이동합니다. **전체** 를 누르면 처음 상태로 돌아갑니다.

**곡 제목 인트로 (선택)**

영상 첫머리에 배경을 흐리게 하고 화면 가운데에 곡 제목과 작곡가를 띄웁니다.

| 칸 | 설명 |
|---|---|
| 곡 제목 / 작곡가 | 둘 다 비워 두면 인트로 없이 시작합니다. 한쪽만 적어도 됩니다 |
| 넣기 | 글자를 지우지 않고 잠깐 꺼 볼 때 씁니다 |
| 길이 | 기본 3초. 끝날 때 0.6초에 걸쳐 글자와 블러가 함께 사라집니다 |
| ▶ 처음부터 | 곡 시작부터 재생해 인트로를 확인합니다 |

제목을 입력하면 미리보기가 인트로 자리로 옮겨가고, 재생할 때도 내보낼 결과와 같은 모양으로 보입니다.
곡 제목을 적어 두면 저장할 때 파일 이름도 곡 제목으로 제안합니다.

> 인트로는 시간을 끼워 넣지 않고 **그 구간의 화면만 바꿉니다.** 전체 길이와 소리 위치는 그대로라서, 인트로 동안에도 소리는 계속 나옵니다.
> 첫 음이 흐린 화면 위로 나오는 게 싫다면 곡 시작을 첫 음보다 2~3초 앞에 잡으세요.

> 시작 페이드가 켜져 있으면 인트로와 함께 검정에서 밝아집니다(기본 1초). 글자를 처음부터 또렷하게 보이고 싶으면 시작 페이드를 `0` 으로 두세요.

## 단축키

| 키 | 기능 |
|---|---|
| `←` `→` | 1프레임 이동 |
| `Shift` + `←` `→` | 1초 이동 |
| `Ctrl` + `←` `→` | 10초 이동 |
| `Space` | 재생 / 정지 (소리 포함) |
| `1` 또는 `A` | 여기서 카메라 A 로 전환 |
| `2` 또는 `B` | 여기서 카메라 B 로 전환 |
| `I` / `O` | 자르기 시작점 / 끝점 |
| `Home` / `End` | 곡 시작 / 곡 끝으로 이동 (싱글캠) |
| `F` | 미리보기 크게 / 작게 |
| `Ctrl` + `S` | 프로젝트 저장 |
| `Delete` | 목록에서 고른 전환점 삭제 |

`1` `2` `A` `B` 와 `Delete` 는 멀티캠 전용입니다.

## 알아두면 좋은 것

**소리는 한 쪽 것만 씁니다.** 카메라가 바뀔 때마다 소리도 바뀌면 음질이 툭툭 끊겨서 듣기 나쁩니다. 그래서 화면만 전환하고 소리는 고른 카메라 것을 통째로 씁니다. 라인 녹음본이 따로 있다면, 그 소리를 입힌 영상을 먼저 만들어 A 로 쓰면 됩니다.

**재생 시 소리는 내보내기의 `소리` 에서 고른 카메라 것이 나옵니다.** 재생 버튼을 누르면 두 영상이 동시에 재생되고, 소리 위치를 기준으로 화면을 맞추기 때문에 오래 틀어놔도 소리와 영상이 어긋나지 않습니다. 재생 시작까지 1초 안팎 걸립니다.

**재생 중 `1`/`2` 키로 전환점을 찍을 수 있습니다.** 곡을 들으면서 실시간으로 컷을 잡는 게 가장 빠릅니다.

**프로젝트 저장** 을 해두면 나중에 이어서 작업할 수 있습니다. 원본 영상 경로와 전환점만 저장되므로 원본을 옮기면 안 됩니다.

**변환 시간**은 대략 영상 길이만큼 (1시간짜리 → 1시간 안팎) 걸립니다. 화질을 `가벼움(빠름)` 으로 하거나 GPU 가속을 켜면 크게 줄어듭니다.

## 문제가 생기면

**"ffmpeg 을 찾을 수 없습니다"** — `setup.bat` 을 다시 실행하고, 창을 전부 닫았다가 `run.bat` 을 실행하세요.

**재생할 때 소리가 안 남** — 아래 순서로 확인하세요.
1. 내보내기 줄의 **소리** 가 소리 있는 카메라로 되어 있는지
2. 재생을 누른 뒤 진행 표시줄 아래에 뜨는 안내 문구 (소리 장치를 못 열면 이유가 표시됩니다)
3. `setup.bat` 을 다시 실행 (소리 재생 모듈 `sounddevice` 설치)
4. 다른 프로그램이 사운드 장치를 독점(ASIO 등)하고 있으면 그 프로그램을 닫고 다시 시도

**자동 싱크가 엉뚱하게 나옴** — 규칙적인 박자 때문에 한 마디 어긋난 곳에 맞을 수 있습니다. 신뢰도가 낮게 나왔다면 위 ② 의 직접 맞추는 법을 쓰세요.

**두 영상이 겹치는 구간이 없다고 나옴** — 시간차 값이 잘못됐을 가능성이 큽니다. 직접 입력한 값이라면 부호(+/−)를 확인하세요.

**동작 점검** — 명령 프롬프트에서 아래를 실행하면 내부 계산이 정상인지 자체 검사합니다.

```
python multicam_editor.py --selftest
```
